# plans/ai/ — AI-Generated Plans (Pending Review)

> **Approved plans live in `plans/active/`** (flat directory, no subdirectories). This directory is the **staging area**
> for AI-generated plans awaiting human review. Once reviewed and approved, plans are moved to `plans/active/` and added
> to `INDEX.md`. Duplicates were cleaned up on 2026-03-13 — if a plan exists in `plans/active/`, it should NOT also be
> here.

This directory holds plans generated by AI agents (Cursor, Claude Code, GHA autonomous agents) that have **not yet been
reviewed and promoted** by a human.

---

## Rules

1. **AI plans go here first** — never directly to `plans/active/`
2. **Cannot block other plans** — do not use a slug from `plans/ai/` as `blocked_by` in an active plan
3. **Ephemeral by default** — if a session task is one-off and produces no persistent work, delete after the session
4. **Do not version or track aggressively** — these are drafts, not commitments

## Promotion to active/ (requires user approval)

When a plan in `ai/` is reviewed and should be tracked long-term:

1. User reviews the plan
2. Check `plans/active/INDEX.md` for slug conflicts and competing `repo_gates`
3. Resolve conflicts (merge, supersede, split, or drop)
4. Rename with `.plan.md` suffix if not already
5. Add the 3-tier YAML frontmatter (`completion_gates`, `repo_gates`, `type`, `epic`) per `plans/PLAN_FORMAT.md`
6. Move to `plans/active/`
7. Add to `INDEX.md` under the correct epic section
8. Commit: `chore: promote <slug> from ai/ to active plans`

## What belongs here

- Plans generated during an audit run (e.g., `plan_readiness_gates_overhaul.plan.md` before promotion)
- Plans drafted by a GHA autonomous agent for human review
- Session-scoped execution checklists
- Draft plans exploring a design that hasn't been approved yet

## What does NOT belong here

- Completed summaries (`*_SUMMARY.md`, `*_STATUS.md`, `*_COMPLETE.md`) — these are banned workspace-wide
- Plans that have already been user-approved — those go directly to `plans/active/`
- Code files, scripts, or config — wrong directory
