## Constraint — full QG can't run in a slot worktree without `setup.sh` first

The per-slot worktrees at `${WORKSPACE_ROOT}/.tabs/<N>/` are created by `setup-tab-worktrees.sh --init` via
`git worktree add` only (~1s/repo) — they do **not** get per-repo `.venv`s. `bash scripts/quality-gates.sh` (which runs
basedpyright + pytest + the 60+ STEP checks) needs the repo's `.venv` with all deps installed. So a full workspace QG
sweep from slot 6 requires running `bash scripts/setup.sh` in each slot repo first (~1-3 min/repo, ~30-60 min for all 22
— affordable over the 4-day cycle but not free). **Plan**: day 1 = static baseline below (ruff + `# type: ignore`,
neither needs a venv); days 2-4 = `setup.sh` + full `quality-gates.sh` on the repos slots 2-5 actually touch, plus a
broader sweep mid-cycle. The full-QG-green check for freeze-gate item 8 will be done on/before 2026-05-14. (The
day-to-day enforcement of QG green is each slot running `bash scripts/quality-gates.sh` before its own pushes per
CLAUDE.md "Commit + Push + Flip" — slot 6 is the cross-cutting validator + regression-attributer, not the only gate.)
