# MTDS Master — Correctness Audit (2026-06-09)

**Mode 1 (Correctness).** Focus per operator request: (1) all adapters working correctly, (2) failure reasons clear +
accurate (honest-absence: fetch failures → `attempted_failed`, never silent `empty_confirmed`), (3) manifests written
correctly, (4) the full Mode-1 checklist (a–k + CF gap items + source-aware/Era-B + bar-edge).

Method: greppable checks run directly; per-adapter failure-path/source/method deep-read split across the cefi+tradfi,
defi, and sports+prediction+perps adapter families (every cited `file:line` was opened and verified on the `8fffc73`
tip). Prod-data-state items (actual `_index` rows, GCS object paths) are flagged **BLOCKED-DATA** — they need an a4/cf
script run against the prod manifest buckets (no GCS creds in this slot).

## Headline

The adapter **mechanics are sound** — bucket-name SSOT, no inline `gs://` business-logic f-strings, no blank
`record_empty` reasons, no subprocess `gsutil`/`gcloud`, canonical underscore data_types, no coarse `pipeline_mode`, and
the Era-B chain remap (`futures_chain`/`options_chain` → `instrument_type` + `data_type=trades`) all GREEN. Cluster
validation and per-VM shard isolation are wired.

The **systemic correctness gap is honest-absence (item i): a recurring "swallow a fetch error → return empty → record as
honest-empty/zero" pattern across DeFi handlers and several batch adapters.** This is exactly the operator's "failure
reasons must be clear + accurate" concern: a swallowed RPC/HTTP/subgraph outage is mislabeled
`empty_confirmed`/`SOURCE_RETURNED_ZERO` in the manifest, corrupting every downstream consumer. **9 RED** swallow sites
(incl. the previously-flagged `lending_indices` item still OPEN) + ~12 AMBER. Plus a **bar-edge left/right leakage**
class on the pre-aggregated tradfi paths.

One audit-doc premise is now **STALE and should be corrected in the instructions**: item (j)'s claim that
`DefiManifestRecorder` "drops `source` entirely" — `record_captured` propagates `source` through the v9 `add()` path
(verified). The real residual is non-captured (`empty`/`failed`/`zero`) DeFi rows being unstamped.
