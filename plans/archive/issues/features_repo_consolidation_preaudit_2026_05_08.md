   `features-delta-one-service/tests/unit/test_feature_groups/test_temporal.py` imports

   `scripts/`. Migration of this family is the longest single-family Phase 3 step.

   repo via the PM rollout system. All collapse to one consolidated repo root copy at Phase 3.

   The migration to the deployment-service launcher SSOT (CLAUDE.md "VM launcher script SSOT") is already complete for
   features-\* (per the in-flight `launcher_scripts_consolidation` plan). Phase 3 doesn't need to touch
   deployment-service for launcher migration. (Two near-launcher scripts surface:
   `features-sports-service/scripts/launch_parallel_backfill.sh` + `run_backfill.sh` — but they're operator helpers, not
   gcloud VM launchers.)

    `("features-<f>-service", "features_<f>_service.api.main", "app")`. Post-merge these collapse to ONE entry:
