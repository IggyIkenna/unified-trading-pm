## Methodology

Read every Execution-area surface in `codex/04-architecture/` (12 anchor docs + the `07-security` redirect). For each
rule / claim / path / address: cite file:line, classify KEEP / LIFT / CONSOLIDATE / DELETE / ADD, attach a 1-line
reason + suggested disposition (IMMEDIATE / PRE_CUTOVER / POST_CUTOVER). Cross-checked against execution-service source
(matching engine + `defi_execution/protocols/{aave,uniswap}.py` + `defi_execution/mev/` + `providers/` +
`trade_execution/factory.py`), UAC (`testnet_contracts.yaml`, `DefiErrorCode`, `BatchExecutionMode`), and UTL
(`config_interface/testnet_contracts.py` `PROTOCOL_SCHEMAS`). Several findings come from grep-then-READ — e.g. the
`DefiErrorCode` "in aave.py" claim is literally false at the import level but the symbol still exists; the
`defi_execution/mev/` modules do exist (early `find` head-truncation made them look missing).
