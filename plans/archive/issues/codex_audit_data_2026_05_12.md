> **Severity**: P1 — pre-cutover audit per `codex_vs_citadel_infrastructure_audit_2026_05_10.md` Phase 1.A. **Scope**:
> 44 codex/02-data docs covering manifest schema, honest-absence taxonomy, available*at semantics, pipeline_mode

## Methodology

For each codex/02-data doc: read body, list every load-bearing claim about (a) manifest schema/columns, (b) reason
taxonomy, (c) bucket/path SSOT, (d) ManifestWriter / record\_\* contract, (e) UAC import surface, (f) pipeline_mode
partition, (g) emission policy, (h) downstream-consumer rules. Cross-validate against UAC + UTL source. Per finding:
cite file:line, classify KEEP / LIFT / CONSOLIDATE / DELETE / ADD, attach disposition (IMMEDIATE / PRE_CUTOVER /
POST_CUTOVER) + owner.

Audit-pass scope: 44 docs / ~11,400 lines across codex/02-data + UAC `honest_coverage.py` (~250 lines) + UTL
`manifest_writer.py` + `bucket_naming.py`.
