# Dependency Manifest SSOT

## External Python Dependencies

**SSOT for external (PyPI) dependency pinning:** `canonical-dependency-manifest.json`

| File                                 | Role                                                                                                                                                                                                                  |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `workspace-constraints.toml`         | **Source** — human/script-editable TOML. Generated by `resolve-canonical-versions.py`. Contains `[dependencies]` with version ranges.                                                                                 |
| `canonical-dependency-manifest.json` | **Derived** — generated from `workspace-constraints.toml` by `scripts/manifest/generate_canonical_dependency_manifest.py`. Machine-readable JSON used by `check_external_dependency_alignment.py`, bootstrap, and CI. |

**Workflow:**

1. Edit `workspace-constraints.toml` (or run `resolve-canonical-versions.py` to regenerate)
2. Run `python scripts/manifest/generate_canonical_dependency_manifest.py` to produce `canonical-dependency-manifest.json`
3. Use `canonical-dependency-manifest.json` as the source for alignment checks and installs

## Internal/Private Repos

**SSOT for internal repos:** `workspace-manifest.json`

Contains `repositories`, `versions`, `topologicalOrder`, dependency graph, etc. Private repos are installed as editable (`pip install -e`) in topological order.
